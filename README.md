# 月度总结工具使用说明

## 概述
本工具用于将每周的文本文件内容汇总成一个月度总结文件。

## 运行步骤
1. **准备每周总结文件**：将所有以 `.txt` 结尾的每周总结文件和 `monthly-summary-tool.py` 脚本放在同一个目录下。
2. **运行脚本**：执行 `monthly-summary-tool.py` 脚本，需要在每周文件所在的文件夹路径。

### 示例命令
```python
python monthly-summary-tool.py
```

### 每周文件内容示例
以下是一个每周总结文件（例如 2025-03-07.txt）的示例内容：
```
运维平台-完成项目 A 的需求分析
运维平台-与团队成员进行了项目 B 的讨论
数据分析平台-小批量数据分析测试
数据分析平台-完成项目 C 的需求分析
```

### 注意事项
- 确保所有每周文件都以 `.txt` 结尾。
- 脚本将从每个文件中提取以 `-` 开头的行作为分类，并将它们汇总到一个月度文件中。
- 月度文件将保存在脚本运行的当前目录下，文件名为 `月.txt`。

## 依赖
本脚本依赖于 Python 标准库，无需额外安装其他依赖。
